# Gallery Images

## Hero Image

**IMPORTANT:** The file `drone-0019.jpg` and `drone-0019.webp` are used as the hero/landing page background image.

**DO NOT optimize, compress, or reduce the quality of these files.**

These images should remain at their current quality to ensure a sharp, professional appearance on the landing page.

If you need to replace the hero image:
1. Use a high-resolution image (minimum 1920x1080, preferably 2560x1440 or higher)
2. Save as both JPG (quality 90+) and WebP (quality 85+)
3. Name the files `drone-0019.jpg` and `drone-0019.webp`
4. Place them in this directory

The landing page uses a `<picture>` element to serve WebP to supported browsers and JPG as fallback.
